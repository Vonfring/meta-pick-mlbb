# Languages: English and Indonesian

The app is available in English (unprefixed URLs, `/tier-list`) and Indonesian (`/id/tier-list`). The welcome page (`/`) is English only. Game data from the sources (hero names, skill names and descriptions, item names and passives, emblem and talent texts) is shown as the source gives it, in English, in both languages.

## How it works

- **Routes.** Every page lives under `src/app/[lang]/`. The root layout there sets `<html lang>` and lists both languages in `generateStaticParams`, so each page is prerendered twice. `next.config.ts` rewrites the unprefixed URLs to `/en/...`; the browser never sees `/en`. The data routes (`/data/v1`, `/api`) sit outside `[lang]`.
- **Which language am I in?** In a Server Component or `generateMetadata`: `const locale = await getLocale()` from `@/i18n/server`. In a Client Component: `const locale = useLocale()` from `@/i18n/client`.
- **Links.** Import `Link` from `@/components/locale-link`, never from `next/link`. It turns `href="/heroes"` into `/id/heroes` on Indonesian pages. For a plain string use `localizeHref(locale, "/heroes")` from `@/i18n/config`. For active states use `useAppPath()` instead of `usePathname()`: English pages are prerendered as `/en/...`, and `useAppPath()` strips the prefix the same way on the server and in the browser.
- **Texts.** Each feature keeps its texts in `src/i18n/messages/<feature>.ts`, defined with `defineMessages({ en: {...}, id: {...} })`. The Indonesian object must have the same keys and function signatures as the English one, or the typecheck fails. Texts with values in them are functions: `heroCount: (n: number) => \`${n} hero\``.
  ```ts
  const t = tierListText[locale];
  <h1>{t.title}</h1>
  ```
  Shared vocabulary (roles, lanes, ranks, periods, item categories, damage types, composition tags, the shell and navigation) is in `src/i18n/messages/common.ts`.
- **Numbers and dates.** `formatPercent`, `formatPoints`, `formatDecimal`, `formatDate` and `formatGold` in `src/lib/format.ts` take the locale as their last argument. Indonesian uses a decimal comma (52,3%) and Indonesian month names (14 Okt 2026). Never build a number string with `toFixed` in a visible text; use `formatDecimal`.
- **Metadata.** Use `pageMetadata(locale, path, { title, description })` from `@/i18n/metadata` in `generateMetadata`. It sets the canonical URL and the `hreflang` alternates for both languages.
- **Unknown URLs.** `src/app/[lang]/[...missing]/page.tsx` calls `notFound()`, so a URL no page matches still gets the app's not-found page, in the right language.
- **Known limits.** The `alt` text of the Open Graph images is a static export, so it stays English in both languages; the text inside the images is localized. When the rank filter is *All ranks*, the label goes into sentences as it is ("in All ranks", "di Semua rank").

## Indonesian style guide

The Indonesian copy is casual, the way a friend who plays a lot of ranked explains things in a mabar group chat. Informal (*tidak baku*), but easy to read for players from anywhere in Indonesia.

**Voice**

- Address the reader as **kamu** (possessive **-mu** or **kamu**). Never *Anda*, never *lo/gue* (too Jakarta-specific and too rough for a tool).
- Use the informal forms consistently:

  | Use | Not |
  |---|---|
  | nggak | tidak, gak, ga, enggak |
  | udah | sudah |
  | aja | saja |
  | kalo | kalau, apabila, jika |
  | pake | pakai, menggunakan |
  | bikin | membuat |
  | bisa | dapat |
  | cuma | hanya |
  | biar | agar, supaya |
  | soalnya | karena (in explanations) |
  | gimana | bagaimana |
  | kayak | seperti |
  | banget | sangat |
  | emang | memang |
  | lagi | sedang |
  | lihat | melihat (*liat* is too sloppy in a UI) |

- Prefer active, short sentences. Drop *adalah*, *merupakan*, *terdapat*, *oleh karena itu*, *silakan*, *harap*.
- Particles (*nih, sih, kok, deh, yuk, dong, kan*) are welcome in descriptions and empty states, at most one per sentence and not in every sentence. Never in buttons, labels, column headers or tab names.
- No *anjay, wkwk, bjir, cuy, gan, gaes*, no emoji, no ALL CAPS, no exclamation marks in a row.
- Buttons and labels are short: *Cari hero*, *Reset*, *Lihat semua*, *Coba lagi*. Headings use sentence case, like the English.

**Game vocabulary.** Indonesian MLBB players use the English terms. Keep them, and attach Indonesian affixes with a hyphen: *di-pick, di-ban, nge-ban, di-counter, ke-counter, nge-push, nge-gank*.

| English | Indonesian |
|---|---|
| hero, heroes | hero (no plural; never *hero-hero*) |
| tier list, tier | tier list, tier |
| win rate, pick rate, ban rate | win rate, pick rate, ban rate (WR only where space is tight) |
| counter, counter pick | counter, counter pick |
| matchup | matchup |
| draft, ban, pick | draft, ban, pick |
| build, item, emblem, talent, battle spell | build, item, emblem, talent, battle spell |
| Tank, Fighter, Assassin, Mage, Marksman, Support | unchanged (the game uses them in Indonesian too) |
| EXP lane, Gold lane, Mid lane, Roam, Jungle | EXP Lane, Gold Lane, Mid Lane, Roam, Jungle |
| roamer, jungler | roamer, jungler |
| Epic, Legend, Mythic, Mythical Honor, Mythical Glory | unchanged; *All ranks* is *Semua rank* |
| Last 7 days | 7 hari terakhir |
| team fight | war |
| frontline, burst, sustain, CC, hard CC, AoE | unchanged |
| mobility | mobilitas |
| early / late game | early game / late game |
| turret, Lord, Turtle | turret, Lord, Turtle |
| physical / magic damage | physical damage / magic damage |
| enemy, enemies | musuh |
| your team, ally | tim kamu, rekan setim |
| teammate | teman setim |
| synergy | sinergi |
| official note | catatan resmi |
| points (scores) | poin |
| statistics | statistik |
| data source | sumber data |

Explain jargon that Indonesian players rarely use (*peel*, *pick-off*) in plain words instead: *jagain carry*, *nangkep musuh yang jalan sendirian*.

**Never translate:** hero, skill, item, emblem and talent names; source texts (skill descriptions, item passives); tier letters (SS to D); product and source names (Metapick MLBB, Moonton, Liquipedia, Mobile Legends: Bang Bang); license names (CC BY-SA 3.0).

**Sentences built from values.** Indonesian word order differs, so write a function per sentence rather than gluing English fragments: `(hero, n, enemy) => \`Win rate ${hero} naik ${n} poin lawan ${enemy}\``. Format numbers with the locale before passing them in.

**If the English is awkward**, fix it too, and keep both languages saying the same thing.
